## Технологии

- **Backend:** Laravel 11 (PHP 8.2)
- **Frontend:** React 18 + Vite
- **База данных:** MySQL 8.0
- **Контейнеризация:** Docker + Docker Compose (версия 2, команда `docker compose`)
- **Веб-сервер:** Nginx (в отдельном контейнере)

## Функциональные возможности

- Просмотр списка всех статей (главная страница)
- Просмотр отдельной статьи с комментариями
- Добавление новой статьи (без авторизации)
- Добавление комментария к статье (без авторизации)
- Автоматическое заполнение базы тестовыми данными (5 статей, у каждой от 0 до 5 комментариев) через сидер

## Требования для запуска

- Установленные **Docker** и **Docker Compose** (версия 2, поддерживающая команду `docker compose`)
- **Node.js** (версия 18 или выше) и **npm** – только для первоначальной сборки фронтенда (можно использовать и внутри контейнера, но проще на хосте)
- **Git** (для клонирования репозитория)

## Запуск проекта

### 1. Клонирование репозитория

```bash
git clone <URL вашего репозитория>
cd <имя папки проекта>
```

### 2. Сборка фронтенда

Фронтенд необходимо собрать, чтобы папка `dist` содержала статические файлы, которые будет отдавать Nginx.

```bash
cd frontend
npm install
npm run build
cd ..
```

### 3. Запуск контейнеров

```bash
docker compose up -d
```

Docker Compose создаст и запустит три контейнера:
- `blog_db` – MySQL
- `blog_app` – PHP-FPM с Laravel
- `blog_web` – Nginx

### 4. Выполнение миграций и наполнение тестовыми данными

```bash
docker compose exec app php artisan migrate --seed
```

Эта команда создаст таблицы в базе данных и заполнит их тестовыми статьями и комментариями (используются фабрики Laravel).

### 5. Проверка работы

- **Фронтенд:** откройте в браузере [http://localhost:8080](http://localhost:8080) – вы увидите список статей.
- **API:** можно протестировать с помощью curl или Postman (базовый URL – `http://localhost:8080`).

## API Endpoints

### Получить все статьи

```bash
curl http://localhost:8080/api/articles
```

Пример ответа (сокращён):

```json
[
  {
    "id": 1,
    "title": "Пример статьи",
    "content": "Текст статьи...",
    "created_at": "2026-02-18T09:05:08.000000Z",
    "updated_at": "2026-02-18T09:05:08.000000Z"
  }
]
```

### Получить одну статью (с комментариями)

```bash
curl http://localhost:8080/api/articles/1
```

Ответ включает поле `comments` с массивом комментариев.

### Создать новую статью

```bash
curl -X POST http://localhost:8080/api/articles \
  -H "Content-Type: application/json" \
  -d '{"title":"Новая статья","content":"Содержание новой статьи"}'
```

Ответ – созданная статья с присвоенным `id` и датами.

### Добавить комментарий к статье

```bash
curl -X POST http://localhost:8080/api/articles/1/comments \
  -H "Content-Type: application/json" \
  -d '{"author_name":"Иван","content":"Отличная статья!"}'
```

## Остановка и удаление контейнеров

```bash
docker compose down
```

Чтобы также удалить том с базой данных (все данные будут потеряны), добавьте флаг `-v`:

```bash
docker compose down -v
```
